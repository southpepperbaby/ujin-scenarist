# HOMIE AI — фронтенд

React 19 + TypeScript + Vite + Tailwind 4 + zustand. Одна кодовая база, две роли:

- `#/resident` — **житель**, мобильный экран: устройства по комнатам, сценарии словами, разбор правила, события;
- `#/uk` — **управляющая компания**, диспетчерская: дашборд, ассистент, инциденты, заявки, устройства, правила, песочница.

Корневой маршрут `#/` — выбор роли.

## Запуск

```bash
npm ci
npm run dev        # http://localhost:5173, /api и /ws проксируются на бэкенд
```

Бэкенд по умолчанию — `http://localhost:8000`, другой адрес задаётся переменной `VITE_BACKEND`
(например, в `frontend/.env.local`). Бэкенд поднимается отдельно (`backend/`, FastAPI) или целиком
через `docker compose up`.

Без бэкенда интерфейс не падает: включается демо-режим с запасным набором (`src/mock/fallback.ts`),
в шапке появляется пометка «демо-данные». Приложение продолжает стучаться к бэкенду с растущей паузой
и само выходит из демо, когда тот поднимется.

```bash
npm run build      # tsc -b && vite build
npm run lint       # oxlint
```

## Структура

```
src/
  api.ts                 клиент HTTP (таймаут 10 с) и WebSocket (переподключение с backoff), типы бэкенда
  store.ts               zustand: устройства, правила, события, уведомления, флаги loaded/demo
  index.css              токены дизайна, светлая и тёмная темы, компонентные классы

  app/                   роутинг по хэшу, выбор роли, загрузка данных, ErrorBoundary
  shared/                общее: форматирование, уровни, тема, тосты, команды палитры
  shared/ui/             примитивы: Button, Modal (<dialog>), Dropdown, Glass, Skeleton, EmptyState…
  shared/rule/           правило словами: чат, конвейер проверки, разбор, включение через прогон
  features/resident/     мобильное приложение жителя
  features/manager/      кабинет УК (грузится отдельным чанком)
  mock/fallback.ts       данные демо-режима
```

## Дизайн-система

Токены объявлены в `src/index.css` через `@theme`: поверхности `canvas`, `surface`, `raised`, `field`,
линии `line*`, текст `ink`, `ink-dim`, `ink-mute`, акцент `accent*`, выбранное состояние `select*`,
статусы `ok`, `sev-info|minor|major|crit` и мягкие подложки `*-soft`.

- **Темы.** Светлая — по умолчанию, тёмная включается на `<html data-theme="dark">` (переключатель
  в шапке кабинета, в профиле жителя и в палитре Ctrl K). Тёмная тема — второй набор тех же переменных,
  вариант `dark:` в Tailwind привязан к атрибуту.
- **Шкала текста.** `text-micro`, `text-caption`, `text-meta`, `text-body`, `text-lead`, `text-title`
  вместо произвольных `text-[13px]`.
- **Поверхности.** `.glass` — только навигация и плавающие слои; контент лежит на плотной `.surface`.
  Компонентные классы стоят в `@layer components`, поэтому утилиты Tailwind их перебивают.
- **Выбранное ≠ тревожное.** Активный пункт меню, вкладка и фильтр — тёмная заливка `select`,
  а тёплая гамма оставлена уровням инцидентов. Уровень различим ещё и формой иконки: круг «i», круг «!»,
  треугольник, восьмиугольник.
- **Контраст.** Вспомогательный текст `ink-mute` держит не ниже 4.4:1 на всех подложках светлой темы,
  пары текст/подложка тёмной темы — не ниже 5.3:1.

Классы Tailwind собираются только из литералов: динамически склеенные имена не попадают в сборку,
поэтому карты стилей в `shared/severity.ts` и `shared/ticket-status.ts` записаны полными строками.

Уровни инцидентов совпадают с политикой автодиспетчера из `docs/concept.md`:
0 — журнал, 1 — минор, 2 — мажор, 3 — критично.

## Клавиатура

- `Ctrl K` / `⌘K` — палитра: разделы, действия («создать заявку», «новое правило»), последние инциденты, устройства.
- `J` / `K` — вниз и вверх по ленте инцидентов, `Enter` раскрывает подробности.
- Окна (`Modal`) — нативный `<dialog>`: фокус заперт внутри, `Esc` закрывает, несохранённая форма спрашивает подтверждение.

## Что откуда берётся

| Экран | Источник |
|---|---|
| Датчики, плитки, песочница | `GET /api/devices`, `POST /api/devices/:id/command`, `inject`, WebSocket `/ws` |
| Сценарии жителя | `GET/PUT /api/rules`, `POST /api/simulate`, `GET /api/rules/:id/explain` |
| Создание правила словами | `POST /api/nl/compile` (LLM + линтер), `POST /api/nl/confirm` (прогон на копии дома) |
| События жителя | `GET /api/notifications?target=resident` |
| Инциденты и вердикты Jev | `GET /api/incidents` |
| Заявки и подрядчики | `GET /api/tickets`, `POST /api/tickets/:id/transition`, `GET /api/contractors` |
